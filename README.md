# tunnel

The quest bots' tunnel: the messages and framing the mh3sp server (the bots' body) and `mh3sp-brain` (their
brain) exchange over one TCP connection. Both use it as a git dependency on its GitHub mirror,
[`mh3-rs/tunnel`](https://github.com/mh3-rs/tunnel), pinned to the same commit.

The GitHub repository is a read-only mirror of `main`, pushed by our CI once the checks pass.
